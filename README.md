# Kernel-Builder

## Requirements
```
figlet (for the logo)
```

## Setup (inside your kernel tree) (running it as user is recommended)
```
git clone https://github.com/karamdev1/Kernel-Builder.git
mv Kernel-Builder/build.sh ./
mv Kernel-Builder/config.cfg ./
rm -r Kernel-Builder
```
Hook your toolchain and arch type in **config.cfg** file and execute the build.sh
